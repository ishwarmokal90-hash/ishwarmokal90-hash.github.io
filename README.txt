PUBLISH FOR FREE WITH GITHUB PAGES
1. Create or sign in to a GitHub account at https://github.com/
2. Create a new public repository named exactly: yourusername.github.io
   (replace yourusername with your GitHub username)
3. Upload index.html, style.css, and script.js from this folder to the repository's root.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait a few minutes and visit https://yourusername.github.io/
7. To update your site later, edit or upload the files in the repository.

This gives you a free address, but it will use your GitHub username. A custom .com domain usually costs money.
Google Search visibility is not immediate or guaranteed. Keep the site public and useful; you can later add the site in Google Search Console.
